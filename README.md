# unitedproconstruction.com

Premium redesign of the United Pro Construction homepage — a CertainTeed ShingleMaster™ & VELUX® certified roofing, siding, gutters, skylight and restoration contractor serving New England.

## Stack
- Semantic HTML5 · CSS3 (custom properties, mobile-first) · Vanilla JavaScript
- No build step, no dependencies — ready for GitHub Pages

## Structure
```
index.html
assets/images/    # Optimized photography & graphics
assets/logo/     # Brand logos (light/dark) + favicon
css/style.css    # All styles (CSS variables, responsive)
js/script.js     # Menu, marquee, FAQ, reviews carousel, lightbox, form
.nojekyll
```

## Notes
- Contact form opens the visitor's mail client via mailto: (no backend by design).
- Demo redesign — `noindex` meta is set so it does not compete with the live site in search results.
- Brand: gold #FFCC29 on charcoal #201E1E; Oswald + Inter typography.
